DOCUMENT CONTROL FROM THE FIELD

How to Build a Practical Project Document Coding System

A document code should tell the project team what the document is, where it belongs and how it can be traced—not just provide a serial number.

Remote deliveryEgypt & Saudi ArabiaConfidential handling

Start with project information

Define the project identifier, relevant zone or package, document owner and discipline before assigning serial numbers.

Separate document types and disciplines

IR, MIR, RFI and shop drawings should remain distinguishable. Architectural, structural, electrical and mechanical work should not disappear into one undifferentiated sequence.

Control revisions consistently

Keep the document reference stable and identify revisions separately so the history of comments, resubmissions and approvals remains visible.

Link the code to the register

A code becomes useful when it appears consistently in the register, submission form, drawing title block and formal correspondence.
