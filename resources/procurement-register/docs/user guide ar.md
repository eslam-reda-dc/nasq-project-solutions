# دليل استخدام قالب سجل المشتريات العربي

## NASQ Project Solutions

هذا القالب أداة Excel عربية مجانية تساعد فرق المشروعات على تسجيل ومتابعة بنود المشتريات والموردين والأسعار ومواعيد الاحتياج والاستلام وحالة كل بند والمستندات المرتبطة به.

## قبل البدء

1. احتفظ بنسخة أصلية من الملف قبل إدخال بيانات مشروعك.
2. افتح الملف باستخدام Microsoft Excel 2021 أو إصدار أحدث، ويفضل Microsoft 365.
3. فعّل تحديث العمليات الحسابية عند فتح الملف إذا طلب Excel ذلك.
4. لا تغيّر أسماء الشيتات أو عناوين الأعمدة حتى تظل المعادلات ولوحات العرض مرتبطة بشكل صحيح.

## الشيتات الموجودة داخل القالب

### 1. سجل المشتريات

هو الشيت الأساسي لإدخال البيانات. اكتب اسم المشروع والعملة في أعلى الشيت، ثم أدخل كل بند في صف مستقل بداية من أول صف فارغ.

البيانات التي يمكن إدخالها تشمل:

- وصف البند.
- الكمية أو العدد.
- الوحدة.
- سعر الوحدة.
- تصنيف الأعمال.
- المستوى أو الطابق.
- المورد.
- رقم عرض السعر.
- رقم أمر الشراء.
- تاريخ الطلب.
- تاريخ الاحتياج.
- تاريخ الاستلام.
- الحالة.
- طريقة الدفع.
- رقم الفاتورة.
- رابط أو مسار فولدر البند.
- الملاحظات.

### 2. لوحة البحث

تستخدم للوصول السريع إلى البنود المسجلة. يمكن البحث بكلمة موجودة في رقم البند أو الوصف أو التصنيف أو المستوى أو اسم المورد، كما يمكن التصفية حسب الحالة أو التصنيف أو المورد.

### 3. لوحة البيانات

تعرض ملخصًا تلقائيًا يشمل:

- إجمالي قيمة المشتريات.
- عدد البنود.
- عدد الطلبات المفتوحة.
- عدد البنود المتأخرة.
- توزيع البنود حسب الحالة.
- إجمالي المشتريات حسب التصنيف.
- إجمالي المشتريات حسب المورد.

### 4. القوائم

هو الشيت المخصص لتعديل الاختيارات المنسدلة. يمكن إضافة أو تعديل الموردين والتصنيفات والوحدات والمستويات وطرق الدفع والحالات من هذا الشيت فقط.

### 5. طريقة الاستخدام

يحتوي على إرشادات سريعة داخل ملف Excel نفسه.

## الأعمدة المحسوبة تلقائيًا

### رقم البند

يظهر تلقائيًا بعد كتابة وصف البند بصيغة تسلسلية مثل `PR-0001`.

### الإجمالي

يتم حسابه تلقائيًا من خلال:

`الكمية × سعر الوحدة`

### مدة التأخير

تحسب من تاريخ الاحتياج إلى تاريخ الاستلام. وإذا لم يتم إدخال تاريخ الاستلام، تتم المقارنة بتاريخ اليوم.

## ربط البند بمستنداته

يمكن إدخال أحد الخيارات التالية في عمود **رابط أو مسار فولدر البند**:

- رابط فولدر SharePoint.
- رابط فولدر OneDrive.
- مسار فولدر على الشبكة الداخلية.
- مسار فولدر محلي على جهاز المستخدم.

عند وجود رابط أو مسار، يتحول رقم البند تلقائيًا إلى رابط يمكن الضغط عليه من داخل Excel.

## ممنوعات العمل على القالب

- لا تكتب داخل أعمدة **رقم البند** أو **الإجمالي** أو **مدة التأخير** لأنها أعمدة معادلات.
- لا تحذف أو تعيد تسمية الشيتات.
- لا تحذف أو تعيد ترتيب الأعمدة الأساسية.
- لا تكتب فوق نتائج لوحة البحث أو خلايا لوحة البيانات.
- لا تحذف شيت القوائم لأنه مسؤول عن الاختيارات المنسدلة.
- لا تلغِ حماية المعادلات إلا إذا كنت تفهم تأثير التعديل على جميع الشيتات.
- لا تنشر نسخة تحتوي على بيانات مشروع حقيقية أو أسعار أو أسماء موردين دون موافقة الجهة المالكة للبيانات.

## نصائح للاستخدام الآمن

- حدّث حالة البنود وتواريخ الاستلام بصورة منتظمة.
- ضع رابطًا منظمًا لمستندات كل بند لتسهيل الوصول إلى عروض الأسعار وأوامر الشراء والفواتير.
- راجع البنود المتأخرة والطلبات المفتوحة من لوحة البيانات أسبوعيًا.
- استخدم نسخة منفصلة لكل مشروع إذا اختلفت الصلاحيات أو الموردون أو العملة.
- احفظ نسخة احتياطية دورية على SharePoint أو OneDrive وفق سياسة مؤسستك.
