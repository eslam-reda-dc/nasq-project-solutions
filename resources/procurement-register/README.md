# NASQ Arabic Procurement Register Template

## محتويات القالب

- سجل مشتريات رئيسي يستوعب حتى 200 بند.
- ترقيم تلقائي للبنود بصيغة `PR-0001`.
- حساب تلقائي لإجمالي كل بند.
- حساب مدة التأخير وفق تاريخ الاحتياج والاستلام.
- لوحة بحث حسب الكلمة أو الحالة أو التصنيف أو المورد.
- لوحة بيانات تفاعلية تعرض المؤشرات والتوزيعات الرئيسية.
- قوائم منسدلة قابلة للتخصيص.
- حماية أعمدة المعادلات ولوحات العرض لتقليل أخطاء الاستخدام.
- إمكانية ربط كل بند بمسار فولدر أو رابط SharePoint أو OneDrive.

## Features

- Arabic procurement register
- Automatic item code
- Auto total calculation
- Delay tracking
- Search panel
- Interactive dashboard
- Dropdown lists
- Protected formulas
- Folder link per item

## Protected Areas

Formula columns, the search output area, and the dashboard are protected to reduce accidental changes and preserve calculation integrity. User-entry fields remain available, while the lists sheet remains editable for customization.

أعمدة رقم البند والإجمالي ومدة التأخير، بالإضافة إلى مناطق نتائج البحث ولوحة البيانات، محمية لتقليل أخطاء المستخدم. وتظل خلايا إدخال البيانات وشيت القوائم متاحة للاستخدام والتخصيص.

## How to Use

1. Enter project and currency details at the top of **سجل المشتريات**.
2. Enter procurement data only in the editable cells of **سجل المشتريات**.
3. Update suppliers, categories, units, levels, payment methods, and statuses only from **القوائم**.
4. Do not edit the item number, total, or delay columns because they contain formulas.
5. Add a SharePoint link, OneDrive link, or folder path in **رابط أو مسار فولدر البند**.
6. Use **لوحة البحث** to find items quickly.
7. Use **لوحة البيانات** to monitor totals, open requests, delayed items, statuses, categories, and suppliers.

- Recommended: Microsoft Excel 2021, Excel 2024, or Microsoft 365.

- A desktop Excel application is recommended for the best experience.

## Privacy

The published template contains no real project records, company names, personal data, or confidential links. Preview images use fictional sample data for demonstration only.

القالب المنشور لا يحتوي على بيانات مشروعات فعلية أو أسماء شركات أو بيانات شخصية أو روابط سرية، وبيانات صور المعاينة افتراضية لأغراض الشرح فقط.
